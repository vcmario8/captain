# AI 来了，大厂招人的画像有哪些？
大厂现状
今年 AI 的普及，对毕业头三年的新人极其友好，因为 AI 把执行的能力抹平了，同时 ai 基建本身也需要熟悉，这个是所有人都在同一起跑线，而工作多年的人，大都是缺乏空杯心态的，而新人天然有主动学习的优势，因此今年各大厂都会抢新人。

自我判断
第一梯队，早几个月拿到了实习的 offer，如果表现优秀就留下来了，说实话实习表现不会太差的，大都能被留下来或者推荐到其他部门。

第二梯队，内推依旧是非常好的渠道，能让你直接拿到面试优势，业界也有不成文规定，能进大厂的，内推的人也不会太差，毕竟物以类聚。

第三梯队，啥信息也没有清澈小伙，需要经过 HR 筛选简历，因为是筛选，会根据学校，项目，ai 使用经历来综合判断，这一环节对学校一般的不友好，毕竟行业供大于求。

人才画像
AI 感兴趣，这里感兴趣不是停留在嘴炮，而是为 AI 付费，买过 codex/claude，并且用完 token，能对谢谢 code agent 原理有一些了解，比如 react，context engineer，MCP，skill，并且有一些个人沉淀的东西，比如当 github 上就很好。

专业能力，专业能力依旧重要，这里考察映射的学习能力，技术岗的话，算法依旧重要，不过不会太难了，希望卷算法的时间需要分配到卷 AI，但知道各种算法优缺点，使用场景，底层原理的同学，依旧是聪明绝顶的标志。

软素质中的自主性，大厂很看重 owner 意识，啥是 owner 意识，这些大家都懂，千万别表现出这些行为，会直接被 pass 的：抱怨，把某件事情的结果过分的归因到外部，比如时间不够，合作方不配合，队友时间投入不够等等，所有不以自我归因的现象都叫抱怨。有了归因后，应该给出解法，每个解法需要有优先级，时间。
