# 为什么大厂 ai coding 转型还未规模化？

最近 claude 和 gpt 都更新了新模型，有一个共同点，新模型不再聚焦更厉害的编码，而是拓展横向能力，比如更好的理解用户操作电脑等。隐隐有个趋势，llm 的智商已经可以解决大部分的问题，因此各大厂商开始不再往深度卷，开始卷横向能力，这可能是一个拐点的信号。

今年和多名大厂超级个体聊天，可以显著感受到个人探索已经相当熟，每个人都有自己和 ai 协作的工作流，也有很多 ai 分身在帮自己交付工作。那为什么还未形成规模化的应用。

个人观点有两个原因。

第一，大厂还在等大规模的共识形成，这些超级个体会各自交流，借鉴，最后取一个交集出来。这种情况依赖组织中超级个体足够多，同时大家愿意无条件 share，而共识也需要时间，估计到年底，会有一个比较共识的规模化方案出来。

第二，超级个体的经验走向规模化的问题，它在 ai 出现前也存在，本质上要求超级个体，从我能完成，变成我能带着团队完成，因此需要从自己的经验中总结出 sop，然后把依赖个人的部分从经验中剥离出去，说人话就是抽象和总结，这恰恰是大部分中低阶同学走向高阶同学的必要沉淀。
现在超级个体比例比较多的还是在中低阶群体，毕竟年轻人面对变化响应更快，这也是大厂把矛头转向水货中层的原因，虽然中层的总结抽象能力强，但应对变化可能没那么积极，也会有经验主义依赖等。
