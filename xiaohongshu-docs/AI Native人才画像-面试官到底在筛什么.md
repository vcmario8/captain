# AI Native 人才画像：面试官到底在筛什么
AI 时代，过往的职级等级都成为参考了，换言之，这个时期所有人都面临被市场重新定价；当下没转型好的同学别动——待在现有岗位上，大厂还在等大规模共识形成，还有转型窗口；一旦出去面试，相当于放弃了转型窗口。
1）核心能力不是"会不会用 AI"
很多人对 AI Native 的理解还停留在"会不会写 prompt""用不用 Copilot"这个层面。但市场需要的是你能不能把 AI 融入真实业务流程，并且沉淀成一套可复用、可检查、可产品化的工作系统。
这个能力可以拆成两条线：一条是主导 AI Agent 应用从 vibe、driver、workflow 到 client 的完整演进；另一条是理解行业经验，能把专家的判断抽象成清晰的流程节点、检查标准和节点之间的跳转关系。
具体说：Vibe 阶段，AI 只是帮你提升个人单点效率；到 Driver 阶段，你开始把经验写成文档，驱动 AI 按步骤完成任务；到 Workflow 阶段，流程节点和跳转关系固定下来，变成团队可复用的工作流；最后到 Client 阶段，不需要 LLM 判断的确定性部分，被代码、规则、表单、状态机和 API 固化下来，形成稳定产品。有这个实践经验的人，就是当下市场比较稀缺的。
2）真正稀缺的是"流程设计能力"
AI 最容易替代的，是流程内部的执行，以及既定流程里的推进动作，这正是过去 <3 年工作经验的同学。但 AI 比较难替代的，是流程抽象、边界判断、质量标准设定和结果责任承担——对应 >5 年以上的领域专家、高级产品经理、架构师这些角色的核心价值。
所以 AI Native 时代真正稀缺的人才，是那种"懂行业、能抽象流程；懂 AI、能工程化流程"的人。面试的时候，你要证明的不是自己用 AI 提了多少效，而是你能不能把一个业务问题，拆成 AI 可以执行、可以检查、可以迭代的系统。未来的竞争力，不是比 AI 更会执行，而是能设计 AI 执行的流程。
3）该怎么准备
沉淀  Agent 开发经验，完整经历 vibe→driver→workflow→client 演进，具备了 Agent 开发的完整经验，当下来看是非常稀缺的。
沉淀领域专家能力，不管是产品、开发、金融还是财经方向的。核心是要具备拆解事务型工作的能力——把一整块事务性工作拆成一个个独立的点，点和点之间有明确的关联，然后自己开始折腾 skill、workflow，用 AI 提效。
